Decoding visual descriptions from neural activity measured by functional magnetic resonance imaging (fMRI) is one of the central challenges at the intersection of cognitive neuroscience and brain-computer interface research. Existing methods mainly represent fMRI signals as Euclidean vectors, failing to fully exploit multiscale structural information within brain regions, which limits both decoding performance and interpretability. In this paper, we propose a topology-aware fMRIto-text framework that integrates topological data analysis with multimodal large language models. The proposed framework consists of three modules: a brain encoder, which extracts cross-subject neural semantic representations; a topological encoder, which characterizes structural features of brain regions through hybrid sampling, activation-weighted distance matrices, and low-dimensional persistent homology; and a decoder, which is built upon DeepSeek-VL2 and a low-rank adaptation strategy to fuse the two types of features and autoregressively generate target text. Experiments on the Natural Scene Dataset demonstrate that the proposed method outperforms representative baseline approaches across multiple text-generation quality metrics, achieving superior results in lexical precision, semantic matching, and consistency with image descriptions. Ablation studies show that introducing the topological encoder significantly improves the consistency between generated descriptions and the ground-truth visual semantics. Further analyses reveal that different functional visual regions exhibit differential sensitivity to part-of-speech categories and semantic categories, providing model-level support for the distributed and cooperative view of visual semantic processing.
